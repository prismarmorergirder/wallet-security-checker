## Security & Privacy

Security and transparency are essential considerations when working with cryptocurrency applications.

SafeWallet is intended to provide wallet monitoring through publicly available blockchain information.

### Security Principles

- Never enter your wallet recovery phrase or private keys into a monitoring application.
- Use public wallet addresses for read-only monitoring.
- Verify downloaded application files before installation.
- Review application permissions and network connections.
- Never approve unexpected wallet transactions.
- Keep your operating system and security software updated.

A public wallet address does not provide authorization to spend cryptocurrency. Private keys and recovery phrases must remain confidential.

**Important:** SafeWallet is not a substitute for a hardware wallet, independent security audit, or professional cybersecurity solution.
